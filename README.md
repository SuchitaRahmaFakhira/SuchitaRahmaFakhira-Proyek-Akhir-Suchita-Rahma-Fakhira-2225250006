## Deskripsi Proyek

Program Generator dan Evaluasi Soal Operasi Hitung Campuran merupakan program berbasis Python yang dirancang untuk membantu pengguna berlatih menyelesaikan soal operasi hitung campuran secara mandiri melalui terminal.

Program ini dirancang untuk menghasilkan soal, menentukan jawaban yang benar, memeriksa jawaban pengguna, dan menampilkan hasil evaluasi latihan.

## Latar Belakang

Operasi hitung campuran merupakan materi matematika yang melibatkan penjumlahan, pengurangan, perkalian, dan pembagian. Dalam menyelesaikan soal, pengguna perlu memahami urutan pengerjaan operasi matematika agar mendapatkan hasil yang benar.

Program ini dirancang untuk menyediakan latihan soal yang bervariasi, memeriksa jawaban secara otomatis, dan memberikan informasi mengenai hasil latihan. Dengan demikian, pengguna dapat berlatih secara mandiri dan mengetahui ketepatan jawabannya.

## Pengguna dan Tujuan

**Pengguna:** Siswa atau pengguna yang ingin berlatih menyelesaikan soal operasi hitung campuran.

**Tujuan:**
- Membantu pengguna berlatih mengerjakan soal operasi hitung campuran.
- Menghasilkan soal latihan sesuai kemampuan program.
- Menentukan jawaban yang benar berdasarkan aturan operasi matematika.
- Memeriksa jawaban pengguna secara otomatis.
- Menampilkan hasil evaluasi latihan.

## Fitur Program

### Fitur Wajib

1. Menghasilkan soal operasi hitung campuran.
2. Menampilkan soal melalui terminal.
3. Menerima jawaban pengguna sesuai mekanisme input program.
4. Menghitung atau menentukan jawaban yang benar.
5. Memeriksa kebenaran jawaban pengguna.
6. Menampilkan hasil evaluasi jawaban.

### Fitur Tambahan

1. Menampilkan langkah penyelesaian soal apabila memungkinkan.
2. Menambahkan variasi tingkat kesulitan soal apabila sesuai dengan pengembangan program.

## Cara Menjalankan Program

1. Pastikan Python telah terpasang di komputer.
2. Buka folder proyek melalui Visual Studio Code.
3. Buka terminal di dalam folder proyek.
4. Jalankan perintah berikut:

```bash
python src/main.py
```

Jika perintah `python` tidak dapat digunakan, coba jalankan:

```bash
python3 src/main.py
```

Program dapat dijalankan setelah implementasi pada `src/main.py` selesai dibuat.

2. Pengguna memasukkan jawaban yang benar.

4. Program menghitung ekspresi sesuai urutan operasi matematika.
5. Program menangani pembagian dengan nol.
6. Pengguna memasukkan input yang tidak valid.
7. Program menampilkan hasil evaluasi jawaban.

Rincian input dan hasil yang diharapkan dicantumkan dalam `tests/test_case.md`. Hasil aktual diisi setelah pengujian program dilakukan.
